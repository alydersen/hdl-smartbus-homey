# HDL SmartBus for Homey

Free and open-source app that connects HDL SmartBus devices to
[Homey](https://homey.app/): relays, dimmers, sensors, dry contacts, floor
heating, curtains, DLP panels and more.

**You need an HDL IP gateway on the bus to use this app.**
